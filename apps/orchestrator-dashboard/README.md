# @eulab/openwaunlocked-orchestrator-dashboard

TanStack Router dashboard for managing open-wa orchestrator sessions.

Part of the [EULAB Open monorepo](https://github.com/Eulab-EugenioRenna/openwaunlocked).

## Development

- `pnpm --filter @eulab/openwaunlocked-orchestrator-dashboard dev`
- `pnpm --filter @eulab/openwaunlocked-orchestrator-dashboard build`
- `pnpm --filter @eulab/openwaunlocked-orchestrator-dashboard start`
- `pnpm --filter @eulab/openwaunlocked-orchestrator-dashboard check`
