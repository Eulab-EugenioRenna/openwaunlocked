# @eulab/openwaunlocked-cli-app

WhatsApp CLI - Easy API mode for @eulab/openwaunlocked

Part of the [EULAB Open monorepo](https://github.com/Eulab-EugenioRenna/openwaunlocked).

## Development

- `pnpm --filter @eulab/openwaunlocked-cli-app build`
- `pnpm --filter @eulab/openwaunlocked-cli-app dev`
- `pnpm --filter @eulab/openwaunlocked-cli-app lint`
- `pnpm --filter @eulab/openwaunlocked-cli-app start`
