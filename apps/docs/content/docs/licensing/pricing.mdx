# Open access

Il fork EULAB offre accesso **Open** alle API nel branch `dev/free-use-offline`.
Non sono richiesti acquisto, abbonamento o chiavi di attivazione.

L'accesso Open non certifica la disponibilità di ogni modulo WhatsApp né la
consegna dei messaggi. Consultare [funzioni e disponibilità](/docs/licensing/licensed-features)
e lo stato delle prove nel checkout, `docs/development/PREMIUM-AUDIT.md`.

Autore e manutentore del fork: **EULAB**. Le condizioni e le attribuzioni del
codice originale sono conservate nei file `LICENSE.md` e `NOTICE.md`.
