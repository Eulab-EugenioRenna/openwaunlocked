# Metodi Eulab Open

Tutti i metodi del registro hanno accesso **Open** nel branch `dev/free-use-offline`, mantenuto da Eulab.

Le implementazioni locali richiedono ancora accettazione live su WhatsApp. La classificazione non prova consegna, rendering o disponibilità dei moduli nativi.

Nel checkout consultare `docs/development/free-use-offline.md` per inventario, alias, limiti e Docker; `docs/development/NEXT-IMPLEMENTATION.md` contiene le attività successive.

Questa pagina riguarda il checkout dev, non certifica i pacchetti pubblicati su npm.
