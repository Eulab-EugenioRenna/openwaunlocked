# @eulab/openwaunlocked-session-sync

Synchronize open-wa sessions to remote storage (S3/Zstd).

Part of the [EULAB Open monorepo](https://github.com/Eulab-EugenioRenna/openwaunlocked).

## Install

```bash
pnpm add @eulab/openwaunlocked-session-sync
```
